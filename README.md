# wagahai-typing

夏目漱石「吾輩は猫である」を丸ごと打てるタイピングゲームのプロジェクトです。

- 作品: 吾輩は猫である（夏目漱石）
- 出典: 青空文庫 作品ID 789 <https://www.aozora.gr.jp/cards/000148/card789.html>
- 底本: 「夏目漱石全集1」ちくま文庫、筑摩書房
- 著作権: パブリックドメイン（著作権保護期間満了）

構成は 2 つに分かれます。

1. **データ生成**（`scripts/generate_data.py`）: 青空文庫の原文から
   タイピング用の構造化データ（原文＋ひらがな読み）を生成・検証する。
2. **タイピングゲーム本体**（`index.html` / `assets/`）: 生成データを読み込んで
   ブラウザで遊べる Web アプリ。

## あそぶ

静的サイトなのでビルド不要です。リポジトリ直下で簡易サーバーを立てて開きます。

```bash
# どちらでも可
python3 -m http.server 8000
# または
npm run serve

# ブラウザで http://localhost:8000/ を開く
```

`file://` で直接開くと `fetch` が使えないため、必ずサーバー経由で開いてください。
GitHub Pages にそのままデプロイすることもできます（リポジトリ直下が公開対象）。

### 遊び方

章選択画面の上部で「プレイモード」を切り替えます。

- **通常モード**: 選んだ章だけをプレイし、章の最後まで打つとリザルトを表示して停止します。
- **エンドレスモード**: 第 1 章から最終章まで、章をまたいで自動で続けて進みます。
  スコアは全章を通した通算でカウントされます。

手順:

1. 章選択画面でプレイモードを選ぶ。
2. 通常モードでは第 1〜11 章から章を選ぶ（選んだ章のデータだけを非同期に読み込みます）。
   エンドレスモードでは「▶ 第1章から全章スタート」を押す。
3. 本文が 1 段落ずつ出題されます。ルビ（ひらがな）のとおりにローマ字で入力します。
4. 段落を打ち終えると自動で次の段落へ進みます。
   - 通常モード: 章の最後まで打つとその章のリザルトが表示されます。
   - エンドレスモード: 章の最後まで打つと「第○章 クリア！ → 第○章へ」と
     トースト通知を出し、次の章のデータを読み込んで段落 1 から続けて進みます。
     最終章（第 11 章）を打ち終えると「全11章走破！完全クリア！」のリザルトを表示します。

操作方法:

- 入力は一般的なローマ字入力を幅広く受け付けます（`し`=shi/si、`ち`=chi/ti、
  `つ`=tsu/tu、`ふ`=fu/hu、`じ`=ji/zi、`しゃ`=sha/sya など）。
- 促音（`っ`）は次の子音の重ね打ち（`tta`）や `ltu` / `xtu` に対応。
- 撥音（`ん`）は `n` / `nn` / `xn` に対応（母音・や行の前では `nn` / `xn`）。
- ミスしても入力は止まりません。正解打鍵数・ミス数・正確率・速度（KPM）を表示します。
- プレイ中はいつでも「← 章選択」または `Esc` で安全に章選択へ戻れます。
- 「この段落をスキップ ⇥」で現在の段落を飛ばせます。

## 生成されるデータ

```
data/
├── raw/
│   └── wagahaiwa_nekodearu.txt   # 青空文庫テキスト(UTF-8) 原文そのまま
├── chapters/
│   ├── chapter01.json            # 章ごとのデータ（1〜11章）
│   ├── ...
│   └── chapter11.json
└── wagahai.json                  # 全章をまとめたデータ（メタ情報＋全段落）
```

規模（自動生成時点）:

| 項目 | 値 |
| --- | --- |
| 章数 | 11 |
| 段落数 | 2245 |
| 本文文字数 | 約 318,000 字 |

## データ仕様

### `data/wagahai.json`

```jsonc
{
  "meta": {
    "title": "吾輩は猫である",
    "author": "夏目漱石",
    "work_id": 789,
    "source": "青空文庫 (https://www.aozora.gr.jp/cards/000148/card789.html)",
    "chapter_count": 11,
    "paragraph_count": 2245,
    "license": "青空文庫 / パブリックドメイン（著作権保護期間満了）"
  },
  "chapters": [
    {
      "chapter": 1,
      "title": "1",
      "paragraph_count": 33,
      "paragraphs": [
        {
          "id": 1,
          "chapter": 1,
          "paragraph": 1,
          "text": "吾輩は猫である。名前はまだ無い。",
          "ruby": "わがはいはねこである。なまえはまだない。"
        }
      ]
    }
  ]
}
```

### `data/chapters/chapterNN.json`

1 章分のオブジェクト（`chapter` / `title` / `paragraph_count` / `paragraphs`）です。
`wagahai.json` の `chapters` の対応する要素と完全に同一です。

### 段落オブジェクト

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `id` | int | 作品全体を通した通し番号（1 始まり、本文順） |
| `chapter` | int | 章番号（1〜11） |
| `paragraph` | int | 章内の段落番号（1 始まり） |
| `text` | string | ルビ・注記を除去した原文（タイプ対象の表記） |
| `ruby` | string | `text` 全体に対応するひらがな読み |

`ruby` は段落全体の読みで、`text` とは 1 文字ずつは対応しません
（漢字 1 文字が複数のかなになるため）。タイピング判定では `ruby`（かな）を
入力対象として用いる想定です。英数字・記号は読みでもそのまま保持されます。

例:

```
text: その上今までの所とは違って無暗に明るい。
ruby: そのうえいままでのところとはちがってむやみにあかるい。
```

## データ生成の仕組み

`scripts/generate_data.py` が以下を行います。

1. 青空文庫のルビ付き Shift_JIS テキスト（作品 ID 789）を取得し、UTF-8 で保存
   （`data/raw/wagahaiwa_nekodearu.txt`）
2. 冒頭の書誌情報・記号の説明と、末尾の底本情報・校正者情報・更新日などを除去
3. 章見出し（`［＃…］一［＃「一」は中見出し］`）で 1〜11 章に分割
4. ルビ解析
   - 青空文庫のルビ（`｜漢字《るび》` / `漢字《るび》`）を最優先で適用
   - ルビのない漢字は [pykakasi](https://github.com/miurahr/pykakasi) でひらがな読みを補完
   - ルビは片仮名ならひらがなへ正規化
   - `［＃…］` 注記、`※［＃…］` 入力者注、`〔〕` アクセント括弧を除去
   - 入力者注の面区点番号（例: `第3水準1-87-64`）は JIS X 0213 として Unicode 文字に復元
5. 章ごとの JSON と全章まとめ JSON を出力

## 使い方

```bash
# 依存関係（データ生成用）
pip install -r requirements.txt

# データ生成（data/raw のテキストを使用）
python scripts/generate_data.py

# 青空文庫からテキストを取得し直してから生成
python scripts/generate_data.py --download

# Python テスト（JSON のパース・欠損・整合性チェック）
python -m unittest discover -s tests -v

# JavaScript テスト（ローマ字入力・対応付け・ゲーム進行）
npm test
```

`data/raw` の生テキストが存在しない場合、`generate_data.py` は自動的に青空文庫から取得します。

```

│   └── js/                  # JavaScript テスト

    ├── chapters/            # 章ごとの JSON（index.json に目次）
    └── wagahai.json         # 全章まとめ JSON
```
